# Improvements for a Transparent Climate-Informed Supply and Demand Energy Forecast

**Code for Eagle Rock Analytics' open-source climate data pipeline for inputs into energy forecasting**

*Motivation*
- To provide fully transparent climate data processing pipeline to prepare complex climate data inputs into CEC supply and demand forecast models
- To identify, diagnose, and provide solutions for sensitivity testing of pipeline components
